AI Translate settings

Everything on this page is stored only in this browser profile on this device.

Get a key at aistudio.google.com/apikey.

Flash models are fast and cheap, which suits page translation. Pro models are slower.

Pick a suggestion or type any language name.

You can name a regional variety, for example "Spanish (Spain)" or "Spanish (Mexico)". Casual uses informal address (tú), Formal uses formal address (usted).

Where your key goes
  • Saved in this browser's local extension storage. It is not synced to your Google or Firefox account.
  • Sent only to generativelanguage.googleapis.com (Google's Gemini API) as a request header, which is how the API authenticates you. The extension is not permitted to contact any other host.
  • Never exposed to the web pages you translate.
  • It is stored unencrypted in your browser profile, like all extension data, so anyone with access to your computer account could read it. "Remove key" deletes it.
